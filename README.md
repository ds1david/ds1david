## About me

I am a **Software Engineer focused on backend systems, architecture and engineering excellence**, with **25+ years in software development** and more than a decade working with modern distributed architectures, microservices and cloud platforms.

My strongest experience is building and evolving **high-volume transactional systems**, particularly in financial services, fintech, telecommunications, logistics and retail. I enjoy solving problems where architecture, performance, reliability and maintainability matter more than simply making the code work.

> **My engineering mindset:** design for scale, make complexity explicit, automate what can be automated, and keep the system observable.

- 🤖 Built an **AI-powered Pull Request review agent** integrated with SonarQube
- 🧩 Designed reusable libraries and internal frameworks to reduce technical complexity
- 🔐 Experience with OAuth2, Keycloak and application security mechanisms
